# V3.62 · The plant models, read again against their photographs (F268)

**The owner:** "I'd like another ranking/rating of the 3d plant sprites against the photos like
previously only with the 'new' designs. This is to see which plants still need more work. Also
distinguishing between the different shrubs is a bit challenging so note ways to make them more
unique perhaps."

V3.48 read all 250 Edmonton natives against their iNaturalist photographs and scored them (mean
3.2, five of 250 at 7 or more). Since then the wildflowers (V3.48's second sitting), the shrubs
(V3.49), the trees and vines (V3.50) and the grasses, sedges and rushes (V3.51) were drawn again
from readings of those photographs, and V3.53 changed the light. V3.48's own plan says the scores
were never re-read after its second sitting: "a re-read is owed before any score is quoted". This
is that re-read. It is a review, not a fix: nothing in the viewer or the catalogue changes here.

## What was run

- The photographs fetched again from iNaturalist's open-data store (it answers from a session;
  the API does not, so the candidate list is still the owner's committed
  `data/fetched/photo_candidates.json`), six at a time.
- `model_references.py fetch`, `render`, `sheets`: every model drawn through the current viewer.
- Every sheet read and recorded with `model_review.py`, the same 0 to 10 question as V3.48:
  *would someone who knows this plant recognise it, and tell it from its neighbours?*

## Changed so the re-read is fair

- `model_review.py` keeps each plant's V3.48 reading under `earlier` when it is read again, and
  keeps its reference photographs when the new reading names none. `compare` prints this pass
  against the last.
- A sheet being read again no longer prints the old verdict in its corner (the reference
  photographs are still framed). Starting from a 3 makes a 3 easier to give.
